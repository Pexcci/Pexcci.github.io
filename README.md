# 张志强的学术个人主页

简洁的响应式学术主页，视觉结构参考 AcademicPages：顶部导航、左侧个人资料、右侧正文内容。

页面仅包含以下基础信息：

- 姓名与英文名
- 学校、学院与专业
- 简短个人介绍
- 研究兴趣
- 邮箱与 GitHub

不包含成绩、排名、奖项、竞赛、证书或其他荣誉信息。

## 文件

- `index.html`：网页内容
- `styles.css`：桌面端与移动端样式
- `script.js`：移动菜单和基础交互
- `standalone.html`：可直接发送到手机打开的单文件版本
- `manifest.webmanifest`、`sw.js`：手机主屏幕与离线访问支持
